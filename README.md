# Escape Tsunami Live Server Page

1. Open `config.js` and paste your private server link inside the quotes.
2. Upload all files to a GitHub repo (index.html, config.js, bg.mp4, theme.jpg).
3. Repo > Settings > Pages > Source: "Deploy from a branch" > main / (root) > Save.
4. Your site goes live at https://YOUR-USERNAME.github.io/REPO-NAME/
